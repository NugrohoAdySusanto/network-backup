# UI & UX Audit Report: Network Backup Portal
Date: 2026-10-17
Auditor: Antigravity AI (antislop Mode 2 & taste-skill)
Scope: Full Application (Header, Navigation, Metrics, Device Table, Modal Dialogs, Typography, & CSS)

---

## Executive Summary
This audit evaluated the Network Backup Portal against the **antislop** standard (Core Rules R-01 to R-38, antislop-ui) and **taste-skill** frontend craft guidelines. The application has strong core functionality, but exhibits several common AI-slop design traits: universal wildcard transitions causing UI lag, widespread forbidden em dashes, excessive glowing and pulsing indicators, inconsistent border radii, cramped floating summary cards in the header, low-contrast muted text, and visual clutter in table row actions.

Each finding below is numbered with its governing rule, priority tier, location, and proposed fix.

---

## Numbered Findings List

### [HIGH PRIORITY] Hard Gate Violations (R-02, R-03, R-25, R-32, R-34)

1. **R-02 (Copywriting / Forbidden Em Dash)**
   - **Rule**: R-02 (Hard Gate)
   - **Reason**: The em dash character (`—`) is strictly forbidden across UI text, labels, and placeholders; it reads as automated template filler.
   - **Locations**:
     - `index.html` L754: `<strong id="device-count">— devices</strong>`
     - `index.html` L930: `<span id="history-hostname-badge">—</span>`
     - `index.html` L968: `<strong id="history-stat-last">—</strong>`
     - `index.html` L1967-1972: Device template presets using `&mdash;`
     - `index.html` L2232, L2244: Table print fallback values `—`
     - `devices.js` L9, L18, L24: Return `"-"` or `"Not yet"` instead of `"—"`
   - **Proposed Fix**: Replace all em dash instances with standard hyphens (`-`), clear placeholders, or contextual text like `"None"`, `"No backups"`, or `"Select device"`.

2. **R-25 (Color Contrast / WCAG AA Standard)**
   - **Rule**: R-25 (Hard Gate)
   - **Reason**: Muted secondary text (`--muted: #647784`) on light background (`--bg-page: #f5f7f8`) has a contrast ratio of ~3.8:1, failing WCAG AA (minimum 4.5:1 for normal body text).
   - **Locations**: `index.html` CSS `:root` (`--muted: #647784`), `.muted` text in table headers, timestamps, and card subtitles.
   - **Proposed Fix**: Darken light-mode `--muted` to `#4b6171` (contrast ratio 5.6:1), and elevate dark-mode `--muted` to `#94a3b8` (contrast ratio 6.2:1) to ensure crisp legibility without eye strain.

3. **R-03 (Mobile Responsiveness / Table Horizontal Disconnect)**
   - **Rule**: R-03 (Hard Gate)
   - **Reason**: Main device table has a rigid `min-width: 1220px;` with no sticky freeze column; scrolling right on tablets or mobile causes the user to completely lose the device hostname context.
   - **Locations**: `index.html` L248 (`table { min-width: 1220px; }`), `L870` (`.table-scroll`).
   - **Proposed Fix**: Freeze the first column (`HOSTNAME`) as a sticky column (`sticky left-0 bg-surface z-10 shadow-sm`) so device names remain anchored while scrolling across backup status and metrics.

4. **R-32 (Keyboard Accessibility & Focus Indicator)**
   - **Rule**: R-32 (Hard Gate)
   - **Reason**: Popover dropdown menus (`#admin-menu`, `.backup-menu`) do not listen to `Escape` key dismissal or trap focus, and table interactive cells lack clean `:focus-visible` outlines.
   - **Locations**: `index.html` L206 (`.pop-menu`), `devices.js` popover handlers.
   - **Proposed Fix**: Add global `Escape` key handlers to close active popovers, add clear 2px offset `:focus-visible` styling to all buttons and select inputs, and ensure logical tab navigation.

5. **R-34 (Theme Integrity / Inconsistent Hardcoded Color Styles)**
   - **Rule**: R-34 (Hard Gate)
   - **Reason**: Several components bypass CSS variables and hardcode Tailwind palette classes (`bg-slate-100 dark:bg-slate-900/90`, hardcoded rgba borders), causing visual flickering and jarring contrast inconsistencies when toggling light/dark themes.
   - **Locations**: `index.html` L1018, L1413, L1659, L1845.
   - **Proposed Fix**: Consolidate all surface, line, and soft background tokens into the unified CSS variable system (`--bg-surface`, `--bg-soft`, `--border-line`).

### [MEDIUM PRIORITY] Purpose-Gate Violations (R-01, R-10, R-11, R-12, R-13, R-14)

6. **R-33 & Performance: Universal Wildcard Transition Lag**
   - **Rule**: R-33 & antislop-ui (Technical Quality)
   - **Reason**: `* { transition: background-color 0.2s ease, border-color 0.2s ease, color 0.15s ease; }` applies transitions to every single DOM node on the page, causing compositor lag and micro-stutters during scrolling and table rendering.
   - **Location**: `index.html` L90-93.
   - **Proposed Fix**: Remove universal wildcard selector; apply smooth transitions selectively only to interactive elements (`button`, `a`, `input`, `select`, `.pop-menu`, `.surface`).

7. **R-13 (Focus Accent / Glow Everywhere & Excessive Pulses)**
   - **Rule**: R-13 (Purpose-Gate)
   - **Reason**: Neon glowing halos and blinking `animate-pulse` animations are placed simultaneously on the Ceph health card, system active tag, table status dots, notice bar, and action buttons, creating visual noise and cheapening the aesthetic.
   - **Locations**: `index.html` L337, L374, L770, L854, L895, `devices.js` L411.
   - **Proposed Fix**: Reserve pulsing animations strictly for live, actively executing backup operations. Replace static glows with clean, solid, high-contrast indicator dots.

8. **R-05 & R-14 (Layout Rhythm / Header Summary Card Cramming)**
   - **Rule**: R-05 & R-14 (Purpose-Gate)
   - **Reason**: Three small summary metric cards are awkwardly squeezed into the top right header navigation next to the user menu and theme button, breaking layout on laptop screens (1024px–1366px).
   - **Location**: `index.html` L751-774.
   - **Proposed Fix**: Extract summary metrics into a dedicated, elegant 3-column KPI bar beneath the header with clean typography, clear labels, and balanced proportions.

9. **R-14 (Table Row Density & Action Button Clutter)**
   - **Rule**: R-14 (Purpose-Gate)
   - **Reason**: Every row in the table permanently displays separate bright green "Save" and red "Clear" buttons, adding visual clutter to every device regardless of whether settings were modified.
   - **Location**: `index.html` L2273-2281, `devices.js` L409-535.
   - **Proposed Fix**: Streamline row actions. Make the "Save" button appear with a subtle badge only when an unsaved change exists (`_pending`), or group row management into an intuitive, compact action group.

10. **R-10 (Excessive Glassmorphism / Heavy Backdrop Blur)**
    - **Rule**: R-10 (Purpose-Gate)
    - **Reason**: Every dialog uses `backdrop-filter: blur(14px)` with high-opacity masks, creating muddy backgrounds and blurring text layers.
    - **Location**: `index.html` L425-429 (`.dialog-backdrop`).
    - **Proposed Fix**: Reduce backdrop blur to a crisp `blur(6px)` with modern slate tint (`rgba(15, 23, 42, 0.65)`), letting dialog surfaces stand out cleanly with defined elevation.

11. **R-11 (Excessive / Inconsistent Border Radius Scale)**
    - **Rule**: R-11 (Purpose-Gate)
    - **Reason**: Random mix of `rounded-2xl`, `rounded-xl`, `rounded-lg`, `rounded-md`, and `rounded-full` across inputs, modals, cards, and buttons with no coherent design hierarchy.
    - **Location**: `index.html` multiple elements.
    - **Proposed Fix**: Standardize on a calibrated 3-tier radius system:
      - Containers & Modals: `16px` (`rounded-2xl`)
      - Cards & Input Fields: `10px` (`rounded-xl`)
      - Buttons & Badges: `8px` (`rounded-lg`)
      - Status Pills: `9999px` (`rounded-full`)

### [LOW PRIORITY] Quality Locks & Taste-Skill Editorial Craft (R-06, R-07)

12. **R-06 & Taste-Skill: Typographic Scale & Editorial Hierarchy**
    - **Rule**: R-06 (Quality Locks) & taste-skill
    - **Reason**: Generic "AI eyebrow" label (`OPERATIONS / NETWORK`) and plain sans-serif styling lack the sharp, professional editorial character expected of mission-critical network tooling.
    - **Location**: `index.html` L746-748, headings across all modals.
    - **Proposed Fix**: Strengthen typographic hierarchy with crisp tracking, refined weight balance between DM Sans and Space Mono, and distinct section anchors.

13. **Taste-Skill: Status Pill Micro-interactions & Visual Polish**
    - **Rule**: Taste-Skill (Craft & Refinement)
    - **Reason**: Status badges ("Active", "Non-Active", "Success", "Failed") use bulky nested rings and borders that look dated.
    - **Location**: `index.html` L288-394 (`.status-cell-wrapper`).
    - **Proposed Fix**: Modernize status badges into sleek, compact pills with solid dots and calibrated color tints that integrate smoothly in both light and dark modes.

14. **Taste-Skill: Modal Header & Close Button Alignment**
    - **Rule**: Taste-Skill (Composition)
    - **Reason**: Modal headers across Backup History, Download Archives, Schedule, Export, and S3 Storage have slightly varying padding, icon sizes, and close button placements.
    - **Location**: `index.html` L917, L1063, L1273, L1476, L1622, L1885.
    - **Proposed Fix**: Unify modal header components into an identical, reusable structure with consistent 20px padding, 40px icon containers, and seamless close buttons.
